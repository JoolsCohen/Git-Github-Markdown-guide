# Git, GitHub и Markdown: практическое руководство

Практическое руководство по основам Git, GitHub и Markdown.  
Материал охватывает установку и настройку Git, работу с локальным и удалённым репозиторием, ветками, Pull Request и базовый синтаксис Markdown.

## Содержание
- Установка и первичная настройка Git
- Основы работы с локальным репозиторием
- Работа с ветками
- Работа с удалённым репозиторием (GitHub)
- Краткий справочник по Markdown

## Формат проекта
- Исходный текст: Markdown
- Финальная версия: PDF
- Дополнительные материалы: скриншоты и примеры

## Структура репозитория
- `manual/git-github-markdown-manual.md` — исходный файл руководства
- `manual/git-github-markdown-manual.pdf` — финальная версия руководства
- `assets/screenshots/` — скриншоты примеров и интерфейсов
- `README.md` — описание проекта

## Как использовать
1. Откройте Markdown-версию руководства в GitHub или VS Code.
2. При необходимости скачайте PDF-версию.
3. Используйте скриншоты как иллюстрации к практическим шагам.
